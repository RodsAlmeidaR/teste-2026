## Teste de Desenvolvimento Web - 2026

Sistema web desenvolvido para o gerenciamento de colaboradores. O projeto permite o cadastro, edição, reajuste salarial (com histórico) e inativação de funcionários, seguindo regras de negócio específicas para bonificações e segurança.

## Tecnologias Utilizadas

* **Node.js** (v24.12.0) - Ambiente de execução Javascript.
* **Express** - Framework web para o backend.
* **SQLite3** - Banco de dados relacional leve (armazenado em arquivo local).
* **EJS** - Motor de visualização (View Engine) para o frontend.
* **Bootstrap 5** - Framework CSS para estilização e responsividade.
* **AJAX (Fetch API)** - Para atualizações assíncronas (Inativação sem recarregar a página).
